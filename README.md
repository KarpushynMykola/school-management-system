# school-management-system
School Management System (Система обліку учнів та класів)

Веб-додаток для автоматизації обліку учнів, навчальних класів.

## Основний функціонал

* **Облік учнів:** Додавання, редагування, вибуття/зарахування.
* **Управління классами:** Формування класів, призначення класних керівників, розподіл учнів по паралелях та літерах.
* **Пошук та фільтрація:** Зручний пошук учнів за прізвищем, класом або статусом.
* **Рольова модель:** Розділення прав доступу (Вчитель, Учень).

---

## Технологічний стек

* **Backend:** Node.js / Express.
* **Frontend:** React.
* **Database:** MongoDB.

## Вимоги
Функціональні вимоги:
1. Управління обліковими записами: Система повинна дозволяти авторизацію за ролями («Вчитель» / «Учень») із відповідним обмеженням прав доступу.
2. Облік учнів: Можливість створювати нові записи учнів, редагувати їхні дані та змінювати статус («Навчається», «Вибув», «Зарахований»).
3. Управління класами: Можливість створювати класи (наприклад, 10-А), призначати класних керівників та розподіляти класи за паралелями і літерами.
4. Розподіл та переведення: Можливість призначати учнів до класів та виконувати масове або поодиноке переведення між классами.
5. Пошук та фільтрація: Функціонал пошуку учнів за прізвищем, класом або поточним статусом.

Нефункціональні вимоги:
1. Продуктивність: Час відгуку системи на запити пошуку або фільтрації не повинен перевищувати 2 секунд при обсязі до 5000 записів.
2. Безпека даних: Хешування паролів у MongoDB через bcrypt.
3. Контроль доступу: аутентифікація через JWT для захисту API-маршрутів Node.js/Express.
4. Зручність використання: Інтерфейс React має бути мінімалістичним та забезпечувати інтуїтивну навігацію з доступом до основних функцій не більше ніж за 3 кліки.
5. Масштабованість: Архітектура сервера має витримувати щонайменше 200 одночасних користувачів.
